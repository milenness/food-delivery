# 🥗 FoodSta

## 🔗 [Live Demo](https://milenness.github.io/food-delivery/)

**FoodSta** is a vibrant and modern landing page for a food delivery service. The project focuses on providing a seamless user experience for browsing healthy meal options and placing orders through an intuitive interface.

## 🚀 Key Features

* **Interactive Slider** — Integrated a smooth slider for easy navigation through the "Some Of Our Favorites" section.
* **Fully Responsive Layout** — Carefully crafted to ensure a perfect look on desktops, tablets, and mobile devices.
* **Functional Order Forms** — Includes interactive forms with validation to enhance user engagement.
* **Performance Optimization** — Fast loading times achieved through optimized image assets and clean, efficient code.

## 🛠 Tech Stack

* **HTML5** & **CSS3** (SASS/SCSS)
* **JavaScript** (ES6+)
* **BEM Methodology** — Used for writing clean, modular, and maintainable styles.
* **Vite** — Utilized as a modern build tool for a fast development workflow.
